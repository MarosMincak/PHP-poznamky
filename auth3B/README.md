# Login projekt – postup spustenia

Všetky potrebné súbory nájdete v priečinku **`parts/`**.

## 1. Vytvorte databázu
- spustite súbor **`parts/create_db.php`**.
- spustite súbor **`parts/create_table.php`**.
- spustite súbor **`parts/insert_data.php`**. (vložte si svoje prihlasovačky do tohoto súboru)

## 2. Vložte testovacieho používateľa
Vytvorte si vlastného používateľa, napr. `mojemeno / mojeheslo`.

## 3. Prihlásenie
Prihláste sa údajmi, ktoré ste vložili do DB (`mojemeno / mojeheslo`).

Po úspešnom prihlásení sa má zobraziť hláška:

**„Ste prihlásený“**

a následne presmerovanie na:

**`logout.php`**  
(táto podstránka ešte nebola na hodine dokončená)
